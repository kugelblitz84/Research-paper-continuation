03 — Shared Hierarchical Training¶

Reviewer quick start: Restart Kernel → Run All. The notebook loads the completed reference run by default and does not retrain or overwrite artifacts. To reproduce training, configure SKIN_CANCER_DATA_ROOT and explicitly set RUN_TRAINING=True.

This notebook reviews the validation-selected Shared Hierarchical EfficientNet-B0 experiment (seed 42). Every input comes from disk; no other notebook's kernel state is required. Install the repository dependencies and Jupyter in the selected kernel before running.

The reference artifacts must be available under experiments/runs/shared_hard_efficientnet_b0_seed42/. If they are absent, the notebook explains what is missing; it does not infer results from old cell outputs. Raw images and a GPU are unnecessary for reviewing saved results.

Saved-output provenance: The configuration, training log, completed summary, history, plots and checkpoint references retained below are the original Azure execution outputs from before this structural cleanup. They have not been regenerated locally. Execution counts are cleared because the code has been reorganized. Restart Kernel → Run All refreshes these outputs from disk; when Azure artifacts are absent, it replaces them with explicit review-mode messages. The untouched original executed notebook is also preserved in validation/evidence/03_shared_hierarchical_training.original.ipynb.
